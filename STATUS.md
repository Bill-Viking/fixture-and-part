## Now
"The Fixture and the Part" — an engineering-drawing-styled interactive guide to transformer internals (React/Vite), built from a static essay with six live instruments (the file, tokenizer, the forward pass drawn live, forward-pass/KV stepper, attention inspector, glass pass). Phase 1 is complete and working: every number is an illustrative heuristic (`src/lib/toyModel.js`), clearly labelled as such, no ML dependency. Phase 2 (real `distilgpt2` via transformers.js) and Phase 3A (the glass pass: per-layer residual stream + logit lens, Instrument D) are verified, merged and deployed, as is Instrument E "the file" (section 01: the real ONNX file — manifest, byte bar, raw-byte blob, byte-exact bell curve, sha-checked re-read; shipped precompute so it shows real facts before any download). The light-theme pass is in progress on the `paper` branch: the page moves off the dark palette onto a white page ground ("Gallery white" — near-white ground, near-black ink, the three role colours at full strength, chosen 2026-08-22 after a cream version was rejected as too beige), dense data fields go onto dark screens set into it, the design tokens are renamed for their colour-law roles, and the copy is rewritten in plain words — including the two moments a reader got stuck on, which are now answered on the page (which sentence every instrument is reading, and what happens to the file when the text changes). Arc 2b is built on branch `forward-pass`, not yet reviewed or merged: a decoding control in instrument B (greedy or a seeded sampled draw, sampled by default, because greedy on a six-block model loops within a few tokens — the greedy path itself is unchanged and verified byte-identical to main), and Instrument F "the forward pass, live" — the whole of distilgpt2 drawn once in section 02, its shapes and byte counts read out of the file's own manifest, with the reader's sentence running down it as one amber column per token, a node at each of the seven residual stops sized by the real ‖residual‖ there, attention threads and twelve lit head squares in the selected block, and lettered windows onto A–E. This is what Bill asked for when he said "the neural net is static — I thought we'd see the weight activations as we ran it". Arc 3 "the waterfall" is built on branch `waterfall` (off 2b), not yet reviewed or merged: the metaphor is that the file is cut rock training carved and inference never touches, and the activations are water falling through it. Every steel box now wears its own tensor as a faint 48×12 whole-tensor thumbnail read out of the real file at build time — real in both modes — which glints amber as the water crosses it; the selected token's residual falls down the drawing as a 768-cell amber strip, one cell per number, morphing at each of the seven stops to that stop's real values and parking wherever a node is clicked; the columns are finally named on the drawing itself; the logit lens whispers what it hears at each depth as the water passes it; and the last stream lands at the unembedding as a splash of the real next-word probabilities with the sampler's actual pick marked. Next arcs: 3B "head room" (all-heads grid), 3C "flow threads" (attention arcs during generation).

## Important
- Colour law is the visual thesis, not decoration: frozen = machinery (weights/dies), moving = the moving part (activations/tokens), keys = searchable metadata — don't swap this mapping. The tokens are named for those roles, so the colours filling them can be repainted (they have been, once) without touching the law.
- Zero layout shift is a standing invariant, and it is measured rather than assumed — CLS via a buffered PerformanceObserver, plus a full document-geometry diff before and after the model load, because a shift below the fold does not register as CLS. Two shifts are known and accepted rather than fixed:
  - Instrument A's token strip reflows when the real model lands and the word-split pills are replaced by BPE pieces (~0.058 at 1280, and only while instrument A is on screen). The pills are genuinely different words of genuinely different widths; the strip's own height is already reserved, so nothing outside it moves. Inherent, pre-existing, and measured identically on the palette before this one.
  - The cache counter in instrument B reports ~2e-6 on the STEP that takes the entry count from one digit to two. The number's box is reserved and does not move; the digits inside it do.
  - Typing measures a hairline — 3.1e-5 at 1280, 6.8e-5 at 390 — from one text node re-wrapping in the prose that quotes the reader's sentence. Measured identically on main to the last digit, so it predates instrument F and the waterfall; it is a sub-pixel reflow of a curly quote, not anything moving.
  - Instrument F adds no third one: model load, typing, STEP×2, token click, layer change, RUN THE PASS, strip park, steel-box click, open-in-file and the decoding toggle all measure 0.000000 with a zero geometry diff at both 1280 and 390. Two shifts it did have were fixed rather than accepted — the layer selector swapping for a ghost line on every STEP and moving the button beside it, and a right-aligned status note whose glyphs walked sideways whenever the wording changed length. Both are the same failure and have the same fix: pin the box, align the text left.
- Phase 1's numbers are explicitly heuristic, not real model output — keep that labelling intact if Phase 2 stays unmerged, so the two modes are never confused.
- Text drawn over a texture cannot be checked from the stylesheet. Instrument F's steel boxes carry a tensor thumbnail under their words, so the ground beneath a glyph is whatever that tensor's bytes happen to be there; contrast has to be measured off the raster (render twice, once with the text hidden, and score every glyph pixel against the pixel underneath it). Doing that found what a stylesheet sweep could not: the selected box's name line had dropped to 4.41:1, below AA across 99.4% of the glyph body. A naive `rgb()` regex is the other half of the same trap — anything built with `color-mix()` resolves to `color(srgb …)` and is skipped silently.
- About 2% of the glyph pixels in instrument F's steel boxes sit below AA where an amber token column crosses the words. Pre-existing and measured on main at the same rate (1.6% here against main's 1.9% at 1280); the median box text reads about 7:1. Worth fixing one day by routing the columns behind the boxes rather than over them.
