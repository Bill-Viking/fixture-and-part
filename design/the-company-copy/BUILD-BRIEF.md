### A6b. The house font never holds the page
`src/main.jsx` (the dress commit) awaits the Barlow stylesheet's `onload`/`onerror` and then `document.fonts.load` for five faces BEFORE the first render. On a network that drops the font host silently (an office firewall, not a DNS failure) `onerror` can take tens of seconds, and the reader sees a blank page meanwhile — the lane's headless still of 2026-10-25 11:5x was blank at 12 s for this reason. Change: race the whole font wait against a 2,500 ms timer (`Promise.race([fontWait, new Promise(r => setTimeout(r, 2500))])`), so the page paints in the local fallback face at 2.5 s at the latest and swaps to Barlow when it arrives (`font-display: swap` is already in the link's URL). Keep the `data-look` set and the css import awaited as they are (the css is local). Say in the hand-back what the fallback face is on macOS and Windows (the company.css `--body` stack: Barlow, Calibri, Arial).
