## 2. `scripts/bake-pass.mjs` — the baker (npm script `facts:pass`)
Plain node (no Vite). Imports `./src/lib/passCore.js`, `DEFAULT_SENTENCE` from `./src/lib/toyModel.js`, `@huggingface/transformers` (its node build) for the tokenizer only, and `onnxruntime-node` (`InferenceSession`) for the session. Model `scripts/read-model-file.mjs` for shape, flags and the no-path-no-user rule of its JSON. Steps, each printing one flushed line `N of M · what · result` (the Progress-line law):
1. THE PUBLISHED BYTES. `--file <path>` or, by default, the first `83502375` bytes of `node_modules/@huggingface/transformers/.cache/Xenova/distilgpt2/onnx/decoder_model_quantized.onnx` (PASS-MAP A5: that cached copy is the published file plus an OLD 291-byte 6-name tail). Its sha256 MUST equal `src/content/fileFacts.json` `provenance.sha256` (`1d3ab4d7e08ca9b8ea9a42dda13a05b7ff0f1b0c9bdc4f6eba27e7f0ceff8431`) and its length `provenance.bytes`; otherwise STOP with both shas printed. Never write to that cache file.
2. THE GRAPH. `withAttentionOutputs(bytes)` appends the CURRENT 14-name fragment (`graphOutputFragment(PROMOTED_OUTPUTS)`). `InferenceSession.create(<those bytes>)` on CPU. Assert `session.outputNames` ⊇ `PROMOTED_OUTPUTS` ∪ {`logits`, `present.0.key`, `present.0.value`} — else STOP `the model graph is missing outputs: <names>` (the same words as realModel.js:267-272).
3. THE TOKENIZER. `AutoTokenizer.from_pretrained('Xenova/distilgpt2')` with `env.allowRemoteModels = false` and `env.cacheDir` set to that same cache folder; the cached `tokenizer.json` sha256 must equal `provenance.tokenizer.sha256` (`cda20b8c…7c66`), else STOP. Tokenize `DEFAULT_SENTENCE` exactly as `realTokenize` does (`tokenizer(text, { add_special_tokens: false })`, ids as Numbers). Assert ids === `[464,3113,45615,290,340,4423,866,13]` (8 tokens, PASS-MAP D) — else STOP and print what came out.
4. THE PASS. `run = await runPass(session, tokenizer, ids)`.
5. THE NAMES. `tokenNames`: `{ [id]: displayToken(tokenizer, id) }` for the 64 highest `lastLogits` ids plus every `candidates[].id`. `nextToken`: what greedy decoding takes at step 0 — read `chooseNext` (realModel.js:780-824) and reproduce its GREEDY branch exactly (if it is just the first candidate with `wins`, say so; if a penalty or skip rule applies, reproduce it); `decode: 'greedy'`.
6. THE FILE. Write `src/content/passFacts.json`:
   `provenance: { bakedAt: 'YYYY-MM-DD' (UTC day, as fileFacts dates its own), sentence, ids, tokens, model: { url, sha256, bytes } (copied from fileFacts.provenance), tokenizer: { url, sha256, bytes } (same), runtime: 'onnxruntime-node <version> · cpu', node: process.version }` — no path, no file name outside the hub's own, no user name;
   `run: { key, n, vocab, ids, tokens, candidates, embeddings, k, v, lastNorm, attention: [6 × base64], residuals: [7 × base64], lastLogits: base64 }` — base64 of each Float32Array's bytes, little-endian, the whole array (RAW fields: no reduction, no rounding — the browser reduces them with its own code);
   `tokenNames`, `nextToken`, `decode`.
   Print: n, ids, tokens, `lo → hi` of the N×7 L2 norms of `residuals` (expected ≈ `5.0 → 1816.7`, the live page's own line), the top 8 of the softmax over `lastLogits` as `token p` (the landing), `nextToken`, the JSON byte size and its gzip size (`gzip -c | wc -c`). These printed numbers are the real-case measure; the lane compares them to the live page.
7. Idempotent: a second run writes a byte-identical file except `bakedAt`.
